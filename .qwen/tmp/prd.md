## Введение

Smart Start Next - это стартовая страница с закладками, которая поддерживает drag-n-drop для управления группами сайтов. Текущая реализация drag-n-drop работает на всех устройствах, но на мобильных устройствах (ширина экрана ≤ 768px) это создает проблемы с удобством использования.

## Проблема

**Текущий процесс:** Drag-n-drop групп реализован на главной странице для всех устройств без исключения.

**Основные пользователи:** Пользователи мобильных устройств (смартфоны, планшеты).

**Проблемные области:**
- Drag-n-drop на сенсорных экранах неудобен и вызывает случайные срабатывания
- Конфликт с нативными жестами прокрутки на мобильных устройствах
- Отсутствие возможности перетаскивания групп на мобильных устройствах в настройках

**Важность:** Улучшение пользовательского опыта на мобильных устройствах критически важно, так как значительная часть трафика приходится на мобильные устройства.

## Цель и Область

**Цель:** Оптимизировать drag-n-drop для мобильных устройств, отключив его на главной странице и добавив в настройки.

**Идеальный результат:** Пользователи мобильных устройств могут удобно управлять порядком групп через настройки, в то время как на главной странице drag-n-drop отключен для предотвращения случайных срабатываний.

### В области или Цели
- Отключение drag-n-drop для групп на главной странице для мобильных устройств (≤ 768px)
- Добавление drag-n-drop для управления группами в настройках (только для мобильных устройств)
- Сохранение drag-n-drop на десктопных устройствах на главной странице
- Сохранение drag-n-drop сайтов на всех устройствах

### Не в области или Не цели
- Изменение drag-n-drop для сайтов (только группы)
- Поддержка устройств с шириной экрана > 768px в настройках
- Изменение визуального стиля компонентов

## Требования к Продукту

### Критические Пользовательские Путешествия (CUJs)

1. **CUJ-1: Пользователь мобильного устройства на главной странице**
   - Шаг 1: Пользователь открывает главную страницу на мобильном устройстве (≤ 768px)
   - Шаг 2: Пользователь пытается перетащить группу
   - Шаг 3: Drag-n-drop не активируется (заблокирован для мобильных)
   - Шаг 4: Пользователь может продолжать использовать страницу без случайных срабатываний

2. **CUJ-2: Пользователь мобильного устройства в настройках**
   - Шаг 1: Пользователь открывает настройки на мобильном устройстве
   - Шаг 2: Пользователь переходит к управлению группами
   - Шаг 3: Пользователь перетаскивает группы для изменения порядка
   - Шаг 4: Порядок групп сохраняется и применяется на главной странице

3. **CUJ-3: Пользователь десктопа на главной странице**
   - Шаг 1: Пользователь открывает главную страницу на десктопе (> 768px)
   - Шаг 2: Пользователь перетаскивает группы
   - Шаг 3: Drag-n-drop работает как прежде

| P0 | Добавить drag-n-drop для групп в настройках для мобильных устройств | Как мобильный пользователь, я хочу перетаскивать группы в настройках, чтобы управлять их порядком |
| P1 | Сохранить drag-n-drop групп на главной странице для десктопов (> 768px) | Как десктопный пользователь, я хочу продолжать использовать drag-n-drop на главной странице |
| P1 | Визуальная обратная связь при drag-n-drop в настройках на мобильных | Как мобильный пользователь, я хочу видеть визуальную обратную связь при перетаскивании групп |

## Предположения

- Мобильные устройства определяются как устройства с шириной экрана ≤ 768px
- Пользователи мобильных устройств реже меняют порядок групп, чем десктопные пользователи
- Настройки уже содержат раздел для управления группами

## Риски и Смягчение

**Риск**: Пользователи могут не найти управление группами в настройках
- **Смягчение**: Добавить четкую подсказку/инструкцию в настройках

**Риск**: Путаница из-за разного поведения на разных устройствах
- **Смягчение**: Добавить tooltip/подсказку на мобильных устройствах при попытке перетаскивания

**Риск**: Проблемы с производительностью drag-n-drop в настройках
- **Смягчение**: Использовать оптимизированную реализацию с теми же хуками, что и на главной странице

## Компромиссы

- **Вариант 1**: Полностью отключить drag-n-drop на мобильных
  - Плюсы: Простота реализации
  - Минусы: Пользователи мобильных устройств теряют функциональность
  - **Выбрано**: Нет

- **Вариант 2**: Переместить drag-n-drop групп в настройки для мобильных
  - Плюсы: Сохранение функциональности, лучшее разделение UI
  - Минусы: Дополнительная реализация
  - **Выбрано**: Да

### Поведение:
- **Главная страница (≤ 768px)**: Drag-n-drop групп отключен

- **Настройки (≤ 768px)**: Drag-n-drop групп включен
- **Настройки (> 768px)**: Drag-n-drop групп не добавляется (не нужен)
